安裝 Chrome 版桌寵

裝好之後，角色會在妳逛的每個網頁下方走來走去。
適用電腦版 Chrome 與 Edge，大約三分鐘。

✦ ZIP ✦下載☝ 點我下載v0.6.0｜2026.11.10
🧩安裝步驟✦ INSTALL ✦
  1. 下載擴充功能 下載後解壓縮，會得到一個 pet-extension 資料夾。
    ✦ DOWNLOAD ✦pet-extension.zip↓
  2. 把資料夾放到固定位置 例如「文件」裡。Chrome 每次啟動都會從這個資料夾讀取，安裝後請保留它，不要刪除或移動。
  3. 打開擴充功能管理頁 在網址列輸入 chrome://extensions 後按 Enter。 Edge 請輸入 edge://extensions。
  4. 開啟「開發人員模式」 在頁面右上角，把開關打開。 Edge 的開關在左側選單下方。
  5. 點「載入未封裝項目」 選擇第一步解壓縮出來的 pet-extension 資料夾。資料夾裡要直接看得到 manifest.json，選錯層會無法載入。
  6. 把圖示釘在工具列 點網址列右邊的拼圖圖示，找到「Q版桌寵」，按旁邊的圖釘。
  7. 選角色 點工具列上的桌寵圖示，最多選四隻，角色會直接出現在網頁上。 安裝前就已經開著的分頁，需要重新整理一次才會出現。
🐾怎麼玩✦ HOW TO PLAY ✦
  • 點一下角色：會有反應
  • 按住拖曳：把角色提起來，放開會掉回地面
  • 滑鼠在頭上左右來回：摸摸頭
  • 按住 Alt 點一下網頁：叫最近的角色跑過來
  • 放著不管：一段時間後會睡著，點一下就會醒；越晚越容易睏
  • 角色生日當天：散步時會飄出慶生的小東西
  • 選兩隻以上時：走到彼此身邊會停下來打招呼；拖起其中一隻，另一隻會轉頭看
  • 暫時不想看到：點圖示，取消勾選「顯示」
❓常見問題✦ Q & A ✦
安裝時提示「讀取及變更所有網站資料」？
這是為了讓角色顯示在每個網頁上。擴充功能只會向本站讀取角色圖片，不會收集或傳送任何網頁內容。
有些網頁看不到角色？
Chrome 的設定頁、擴充功能商店和新分頁空白頁，瀏覽器規定擴充功能不能出現。影片全螢幕時角色也會暫時隱藏。
Chrome 跳出停用開發人員模式擴充功能的提醒？
因為這個擴充功能沒有上架商店，Chrome 偶爾會提醒。選擇保留或直接關掉提醒即可。
手機可以用嗎？
手機版 Chrome 不支援擴充功能，請改用網頁版。
🔄更新與移除✦ UPDATE ✦
  • 新角色：不需要重新安裝。點圖示，按「重新讀取名冊」就會出現。
  • 擴充功能改版：重新下載 zip，解壓縮後覆蓋原本的資料夾，再到 chrome://extensions 按桌寵卡片上的重新載入箭頭。
  • 移除：到 chrome://extensions，在桌寵卡片上按「移除」，再刪掉資料夾即可。
